1. Foundation

Fundamentals of Matrices

What is a Matrix?

A rectangular array of numbers, symbols, or expressions arranged in m rows and n columns.

A =
a11 a12 a13
a21 a22 a23

Dimension is expressed as m × n (Rows × Columns).

Key Matrix Types

  • Square Matrix: Same number of rows and columns (m = n). Required for determinants and inverses.
  • Identity Matrix (I): Diagonal contains 1s, all other entries are 0. Serves as '1' in matrix algebra.
  • Zero Matrix (O): Matrix with all zero entries.

Matrix Determinant (|A| or det A)

2×2 Determinant Formula

A scalar value calculated strictly for square matrices.

Singular vs Non-Singular

  • Singular Matrix: det(A) = 0. The matrix has no inverse.
  • Non-Singular Matrix: det(A) ≠ 0. The matrix is invertible.
  • Geometric View: Determinant measures the area/volume scaling factor of a transformation.

5. Sign Patterns

Cofactor of a Matrix (Cij)

The Cofactor Formula

A cofactor is a minor with a position-based sign (+ or −) applied.

Cij = (−1)i + j · Mij
  • If (i + j) is EVEN: Cij = +Mij
  • If (i + j) is ODD: Cij = −Mij

Checkerboard Sign Grid

+−+
−+−
+−+

Signs alternate across every row and column.

6. Matrix Transformation

Cofactor Matrix & Adjugate (adj A)

1. Cofactor Matrix (C)

Replace every entry aij in Matrix A with its calculated cofactor Cij.

C =
C11 C12 C13
C21 C22 C23
C31 C32 C33

2. Adjugate Matrix (adj A)

The Adjugate is the Transpose of the Cofactor Matrix C.

adj(A) = CT

Swap rows with columns: element Cij moves to position (j, i).

7. Core Concept

Inverse of a Matrix (A−1)

Formula & Rules

A−1 = 1/det(A) · adj(A)
  • Fundamental Rule: A · A−1 = A−1 · A = I
  • Existence Condition: Inverse exists only if det(A) ≠ 0.
  • 2×2 Shortcut:
    1. Swap main diagonal elements.
    2. Change signs of off-diagonal elements.
    3. Divide by det(A).

8. ALGORITHM

Step-by-Step Inversion Pipeline

  • Step 1: Calculate Determinant: Find det(A). If det(A) = 0, stop! (No inverse).
  • Step 2: Build Minor Matrix: Compute all minors Mij.
  • Step 3: Apply Sign Grid: Multiply minors by (−1)i+j to build Cofactor Matrix C.
  • Step 4: Transpose C: Swap rows and columns to obtain Adjugate Matrix adj(A) = CT.
  • Step 5: Scale: Multiply adj(A) by scalar (1 / det A) to get final inverse A−1.

10. REAL-WORLD APPLICATION 2

Cryptography: Hill Cipher

1. Encrypting (Scrambling Text)

Letters are converted to numbers (A=0, B=1...). We multiply text blocks by a secret Key Matrix (K) to lock and scramble the message.

Ciphertext = ( K · Message ) mod 26

💡 Analogy: Matrix K acts as a digital lock that scrambles readable text into hidden code.

2. Decrypting with Inverse (K−1)

To read the message, the recipient must "undo" matrix multiplication using the secret Inverse Matrix (K−1).

Message = ( K−1 · Ciphertext ) mod 26

🔑 Key Requirement: If det(K) = 0, no inverse matrix exists — meaning the lock could never be opened!

11. REAL-WORLD APPLICATION 3

Solving Systems of Equations & Engineering

Matrix Equations

Systems of linear equations are expressed in matrix form and solved directly using the inverse matrix:

A · x = b   ⟹   x = A−1 · b

💡 Key Concept: Multiplying by A−1 isolates vector x, solving thousands of equations at once.

Practical Engineering

  • Electrical Circuits: Solving Kirchhoff's current and voltage laws for complex node voltages.
  • Structural Engineering: Calculating stress, strain, and load capacity on bridges using finite element stiffness matrices.

Matrix A  ⟹  det(A)  ⟹  Minors Mij  ⟹  Cofactors Cij  ⟹  adj(A)  ⟹  Inverse A−1
