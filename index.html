Matrix Transposition (AT)

Definition & Mechanical View

The transpose of an m × n matrix A is an n × m matrix AT formed by converting rows into columns (and vice versa).

Element Mapping: (aij) ⟹ (aji)
Example (3 × 2 ⟹ 2 × 3):
A =
23
45
01
⟹ AT =
240
351

Fundamental Properties of AT

  • Additivity & Subtraction:
    (A ± B)T = AT ± BT
  • Scalar Scaling:
    (k·A)T = k·AT
  • Reversal Rule (Multiplication):
    (A · B)T = BT · AT (Notice order reversal!)
  • Double Transpose:
    (AT)T = A
  • Inverse Transpose:
    (A−1)T = (AT)−1

6. Determinants

Matrix Determinant (|A| or det A)

2×2 Determinant Calculation

Calculated by cross-multiplying main and anti-diagonals.

det
ab
cd
= (a·d − b·c)
Example: det | 4   3 ; 1   2 | = (4·2 − 3·1) = 5

Invertibility Condition

✔ Non-Singular (Invertible): det(A) ≠ 0

Matrix has a unique inverse. Area scaling factor > 0.

❌ Singular (Non-Invertible): det(A) = 0

No inverse exists! Transformation collapses area to 0.

Calculating 3×3 Determinant

Rule of Sarrus (Formula)

Sum of 3 main diagonal products minus 3 anti-diagonal products:

det(A) =
+ (a₁₁a₂₂a₃₃ + a₂₁a₃₂a₁₃ + a₁₂a₂₃a₃₁)
− (a₁₃a₂₂a₃₁ + a₂₃a₃₂a₁₁ + a₁₂a₂₁a₃₃)

💡 Tip: You can also use cofactor expansion along any row or column with the most zeros.

9. Matrix Elements

Laplace Expansion (Cofactor Expansion)

Expansion Along Any Row / Column

The determinant equals the sum of elements multiplied by their corresponding cofactors:

det(A) = ai1Ci1 + ai2Ci2 + ... + ainCin
💡 Best Strategy: Choose the row or column with the most zeros to minimize calculations!

Practical Example

Expand along Row 1:

det(A) = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃

Using elements from Row 1 = [1, 2, 3]:
det(A) = 1·(C₁₁) + 2·(C₁₂) + 3·(C₁₃)

Allows calculating n×n determinants easily!

10. Matrix Inverse

Inverse Matrix (A−1)

Definition & Formula

The inverse matrix A−1 satisfies: A · A−1 = A−1 · A = I (where I is Identity Matrix).

A−1 = ¹⁄det(A) · adj(A)
⚠️ Requirement: Exists ONLY if det(A) ≠ 0 (Non-singular matrix).

11. Matrix Inverse

4-Step Algorithm for 3×3 Matrix Inverse

The 4-Step Process

Step 1: Find det(A). Ensure det(A) ≠ 0.
Step 2: Build Matrix of Minors Mij.
Step 3: Apply sign pattern to get Cofactor Matrix Cij.
Step 4: Transpose C to get Adjugate: adj(A) = CT.

Final Formula & Warning

A−1 = ¹⁄det(A) · CT
⚠️ Common Mistake: Don't forget to transpose the cofactor matrix! adj(A) = CT, not C.

12. Matrix Inverse

Key Properties of Matrix Inverse

Algebraic Properties

1. Involution (Double Inverse)
(A−1)−1 = A
2. Product Rule (Reversibility)
(A · B)−1 = B−1 · A−1
⚠️ Note: Order reverses!
3. Transpose Interchange
(AT)−1 = (A−1)T

Determinant & Scalar

4. Determinant Relationship
det(A−1) = ¹⁄det(A)
5. Scalar Multiplication
(k · A)−1 = ¹⁄k · A−1
(where k ≠ 0)
💡 Key Takeaway: Matrix multiplication order is critical when distributing inverses!

13. ALGORITHM

Step-by-Step Inversion Pipeline

  • Step 1: Calculate Determinant: Find det(A). If det(A) = 0, stop! (No inverse).
  • Step 2: Build Minor Matrix: Compute all minors Mij.
  • Step 3: Apply Sign Grid: Multiply minors by (−1)i+j to build Cofactor Matrix C.
  • Step 4: Transpose C: Swap rows and columns to obtain Adjugate Matrix adj(A) = CT.
  • Step 5: Scale: Multiply adj(A) by scalar (1 / det A) to get final inverse A−1.

15. REAL-WORLD APPLICATION 2

Cryptography: Hill Cipher

1. Encrypting (Scrambling Text)

Letters are converted to numbers (A=0, B=1...). We multiply text blocks by a secret Key Matrix (K) to lock and scramble the message.

Ciphertext = ( K · Message ) mod 26
💡 Analogy: Matrix K acts as a digital lock that scrambles readable text into hidden code.

2. Decrypting with Inverse (K−1)

To read the message, the recipient must "undo" matrix multiplication using the secret Inverse Matrix (K−1).

Message = ( K−1 · Ciphertext ) mod 26
🔑 Key Requirement: If det(K) = 0, no inverse matrix exists — meaning the lock could never be opened!

Key Takeaways & Summary

Logical Execution Chain

The step-by-step process of finding the inverse matrix:

Matrix A  ⟹  det(A)  ⟹  Minors Mij  ⟹  Cofactors Cij  ⟹  adj(A)  ⟹  Inverse A−1

📌 Workflow: Each step builds directly on the previous computation.

Key Summary Points

  • Check Determinant First: If det(A) = 0, no inverse matrix exists.
  • Core Identity: A · A−1 = I.
  • Practical Importance: Foundation of 3D graphics, AI optimization, cryptography, and structural engineering.
